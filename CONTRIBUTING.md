# Contributing to Openness

Thank you for your interest in contributing.

This repository is the project home: the README, the license, and the install scripts. The scanner itself lives in two repositories:

- [openness-collector](https://github.com/s4e-io/openness-collector) collects evidence on a host.
- [openness-resolver](https://github.com/s4e-io/openness-resolver) turns that evidence into findings.

Code, feeds, and vulnerability decisions belong in those repositories. Use their contributing guides.

## Before you start

1. Read [README.md](README.md).
2. Follow the [Code of Conduct](CODE_OF_CONDUCT.md).
3. For a vulnerability, see [SECURITY.md](SECURITY.md). Do not open a public issue for it.

## Pull requests

1. Fork and branch from `dev` (the default branch). Pull requests go to `dev`.
2. Keep the change focused.
3. Do not commit credentials, customer evidence, or host-specific data.

A pull request does not need a second approver. A maintainer reads it and merges it.
