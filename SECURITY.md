# Security Policy

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report them through one of:

- [GitHub Security Advisories](https://github.com/s4e-io/openness/security/advisories/new) (preferred)
- Email: **support@s4e.io**

We aim to acknowledge reports within **72 hours** and provide a remediation timeline when possible.

## Where to report

- Install scripts and files in this repository: here.
- Evidence collection: [openness-collector](https://github.com/s4e-io/openness-collector/security/advisories/new)
- Vulnerability decisions: [openness-resolver](https://github.com/s4e-io/openness-resolver/security/advisories/new)

The same address, **support@s4e.io**, reaches us from any of the three.

## Sensitive data

Never commit credentials, customer evidence, or a real host inventory.
